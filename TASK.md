# Задание

- Провалидируй продукт, аудиторию и цель до вызова внешнего сервиса.
- Опиши асинхронный протокол AI-провайдера.
- Создай детерминированный demo-провайдер для разработки и тестов.
- Интегрируй актуальный `google-genai` через `client.aio`.
- Обработай таймаут как `504`, ошибку провайдера и пустой ответ как `502`.
- Выбирай провайдер dependency и добейся прохождения `uv run pytest` без ключа.
